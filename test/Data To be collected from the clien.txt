Data To be collected from the client  
Gather following data as well as other relevant data from the client machines 

Network signals

Netflow/session summaries: src/dst IPs, ports, bytes, duration, packet counts, protocol, TLS SNI/JA3 fingerprint, DNS queries and responses, DNS request patterns, unresolved domains.

Suspicious external connections (rare geolocation, high-risk ASN).

HTTP host/path, user-agent string.

Process & host signals

Running processes: name, PID, parent PID, start time, executable hash (SHA256), command line (trim/hashed if sensitive).

Loaded modules/DLLs and their hashes.

Privilege escalations, sudden svchost anomalies, new service installs, scheduled tasks, WMI persistence objects.

High CPU/memory spikes and anomalous child process trees (process lineage).

New/modified autostart entries (registry, systemd units).

Filesystem

File creation events (metadata: path, size, timestamp, owner, extension), suspicious extensions (.scr, .js, .hta), new files in temp or startup folders.

Hashes of new executables (send only hashes or features).

System calls & kernel events

Syscall sequences or counts for key processes (if performance allows), anomalous syscall patterns.

User behavior

Login events, failed login counts, simultaneous sessions, new user account creations, interactive vs non-interactive sessions.

Binary features for malware

PE features: import table, section entropy, entry point, resource anomalies .

If allowed, sandbox dynamic traces (APIs called, network callbacks) but consider privacy and size.

External Threat Intelligence

IoCs (hashes, domains, IPs), TTP mapping, dark-web NLP outputs.

Meta

Device role (workstation/server), department, criticality label (so RL knows business impact).

Time-stamps and unique but non-identifying host ID.
