### 2.2 Mathematical Explanation

#### Convergence Metric: Euclidean Distance

The system tracks convergence using **L2 norm** (Euclidean distance) between successive model versions:

```
Δ_t = ||θ_t - θ_{t-1}||_2

Where:
- θ_t = global model parameters at iteration t
- ||·||_2 = Euclidean norm (sqrt of sum of squares)
```

**Expanded:**

```
If θ has parameters [w1, w2, ..., wn]:

Δ_t = √[(w1_new - w1_old)² + (w2_new - w2_old)² + ... + (wn_new - wn_old)²]
```

## 3. ANOMALY DETECTION MODELS

### B. Autoencoder (Neural Network)

```python
Input Layer (120 features)
    ↓
Dense(64) + ReLU + Dropout(0.2)
    ↓
Dense(32) + ReLU + Dropout(0.2)  ← Bottleneck (compressed representation)
    ↓
Dense(64) + ReLU + Dropout(0.2)
    ↓
Dense(120) + Sigmoid              ← Reconstruction
```

- **Training**: Learns to reconstruct normal patterns
- **Anomaly Detection**: High reconstruction error = anomaly
- **Threshold**: Set to 90th percentile of training errors
- **Not Shared**: Architecture stays local

### C. Statistical Z-Score Filter

- **Formula**: z = (x - μ) / σ
- **Threshold**: |z| > 8.0
- **Baselines**: EMA (Exponential Moving Average) tracked
- **Shared**: Global mean/std from federated aggregation

### D. OneClassSVM (Optional)

- **Type**: Support Vector Machine for novelty detection
- **Kernel**: RBF (Radial Basis Function)
- **Parameter**: ν = 0.05 (5% outlier tolerance)
- **Not Shared**: Model stays local

### 3.2 Ensemble Scoring

When detecting anomalies, all models vote:

```python
# Each model provides score 0-10
iso_score = isolation_forest.score(features)
ae_score = autoencoder.reconstruction_error(features)
zscore_score = z_score_filter.score(features)
svm_score = one_class_svm.score(features)

# Weighted average
ensemble_score = (0.3*iso + 0.3*ae + 0.2*z + 0.2*svm)

# Severity levels
if ensemble_score > 7.0: severity = 'critical'
elif ensemble_score > 5.0: severity = 'high'
elif ensemble_score > 3.0: severity = 'medium'
else: severity = 'low'
```

### 3.3 CRITICAL ISSUE: Training on Own Data

**Current Problem:**
- Clients train models on **their own live data**
- No validation dataset used
- **Risk**: Models learn site-specific patterns, not generalizable threats
- **Example**: If a client's normal traffic is 100 MB/s, model learns this as "normal"
  - But 100 MB/s might be exfiltration for another client with 10 MB/s baseline

**Why This is Wrong:**
1. Overfitting to local environment
2. No ground truth for anomalies
3. Can't validate detection accuracy
4. Federated aggregation combines incompatible baselines

### 5.2 Privacy-Enhanced FL Code

**Client Side:**

```python
class PrivacyEnhancedDetector:
    def __init__(self):
        # Load pre-trained models
        self.isolation_forest = load_pretrained_model('iso_forest.pkl')
        self.autoencoder = load_pretrained_model('autoencoder.h5')

        # Fine-tune on local data (OPTIONAL)
        self.fine_tune_on_local_data(privacy_budget=0.1)

    def fine_tune_on_local_data(self, privacy_budget):
        """
        Fine-tune with differential privacy
        Only adjusts last layer of autoencoder
        """
        # Add DP noise to gradients
        for gradient in compute_gradients():
            clipped_grad = clip_gradient(gradient, C=1.0)
            noisy_grad = clipped_grad + gaussian_noise(σ=privacy_budget)
            apply_update(noisy_grad)

    def prepare_privacy_safe_update(self):
        """
        Compute model update without exposing data
        """
        # Compute gradient differences
        delta_weights = current_weights - previous_weights

        # Clip L2 norm
        norm = l2_norm(delta_weights)
        if norm > CLIP_BOUND:
            delta_weights *= CLIP_BOUND / norm

        # Add DP noise
        delta_weights += gaussian_noise(σ=DP_NOISE)

        return {
            'weight_deltas': delta_weights,
            'samples_used': len(local_buffer),  # Count only, not data
            'update_norm': norm
        }
```

**Server Side:**

```python
class PrivacyAwareServer:
    def aggregate_updates(self, client_updates):
        """
        Secure aggregation without seeing client data
        """
        # Verify all updates are privacy-compliant
        for update in client_updates:
            assert update['update_norm'] <= CLIP_BOUND
            assert 'raw_features' not in update  # Should never be present

        # Trimmed mean aggregation
        aggregated = trimmed_mean_aggregate(client_updates)

        # Add server-side DP noise

        # Validate improvement
        if not self.validate_improvement(aggregated):
```

## 6. FEDERATED LEARNING BEST PRACTICES

### 6.1 Differential Privacy Parameters

**Client-Side:**

```python
# Per-client privacy budget (ε)
EPSILON_PER_ROUND = 0.1

# Noise scale (σ)
SIGMA = sqrt(2 * log(1.25/DELTA)) / EPSILON
# Where DELTA = 10^-5 (failure probability)

# Gradient clipping bound
CLIP_BOUND = 5.0  # Adjust based on model
```

**Server-Side:**

```python
# Additional privacy amplification
SERVER_EPSILON = 0.05
SERVER_SIGMA = sqrt(2 * log(1.25/DELTA)) / SERVER_EPSILON

# Total privacy cost after T rounds:
TOTAL_EPSILON = sqrt(T) * EPSILON_PER_ROUND  # By composition
```

### 6.2 Secure Aggregation Protocol

For maximum privacy, implement **secure multi-party computation**:

```python
# Clients create secret shares of their updates
def create_secret_shares(update, num_clients):
    shares = []
    for i in range(num_clients - 1):
        shares.append(random_vector(size=update.shape))

    # Last share makes sum = original update
    last_share = update - sum(shares)
    shares.append(last_share)

    return shares

# Server aggregates shares without seeing individual updates
def aggregate_shares(all_shares):
    # Each client sends one share to server
    aggregated = sum(all_shares)  # Recovers sum of original updates
    return aggregated / len(all_shares)  # Average
```

### 6.3 Convergence Monitoring

**Better convergence metrics:**

```python
# 1. L2 norm (current implementation)
delta_l2 = ||θ_new - θ_old||_2

# 2. Cosine similarity (direction alignment)
cosine_sim = (θ_new · θ_old) / (||θ_new|| * ||θ_old||)

# 3. Parameter-wise variance
var_params = mean(variance(θ_i across clients))

# 4. Validation AUC improvement
delta_auc = AUC_new - AUC_old

# Convergence criteria:
if (delta_l2 < 0.01) AND (cosine_sim > 0.99) AND (delta_auc < 0.001):
    model_converged = True
```

## 8. MATHEMATICAL FORMULAS SUMMARY

### Differential Privacy Guarantee

For mechanism M and datasets D, D' differing by one record:

```
Pr[M(D) ∈ S] ≤ e^ε × Pr[M(D') ∈ S] + δ

Where:
- ε = privacy budget (smaller = more private)
- δ = failure probability (typically 10^-5)
```

### Gaussian Mechanism:

```
M(D) = f(D) + N(0, σ²)

Where σ = (Δf / ε) × sqrt(2 × ln(1.25/δ))
And Δf = sensitivity of function f
```

### Federated Averaging (FedAvg)

```
Global model update:
θ_{t+1} = Σ(n_k/n) × θ_k

Where:
- θ_k = local model from client k
- n_k = number of samples at client k
- n = Σn_k (total samples across all clients)
```

### With gradient clipping:

```
For each client gradient g_k:
1. Compute norm: ||g_k||_2
2. If ||g_k||_2 > C:
   g_k ← g_k × (C / ||g_k||_2)
3. Aggregate: g_global = (1/K) × Σg_k
```

### Convergence Delta (L2 Norm)

```
Δ_t = ||θ_t - θ_{t-1}||_2 = sqrt(Σ(θ_t^i - θ_{t-1}^i)²)

Convergence when: Δ_t < threshold (e.g., 0.01)
```

### Ensemble Anomaly Score

```
Score = w_iso × S_iso + w_ae × S_ae + w_z × S_z + w_svm × S_svm

Where:
- S_iso = Isolation Forest score (normalized 0-10)
- S_ae = Autoencoder reconstruction error (normalized)
- S_z = Z-score magnitude (scaled)
- S_svm = SVM decision distance (scaled)
- w_i = weights (sum to 1.0)
```

## 9. KEY TAKEAWAYS

### Current Problems:

1. ❌ **Privacy violation**: Raw client data sent to server
2. ❌ **No validation datasets**: Models trained on own data
3. ❌ **Overfitting risk**: Site-specific patterns, not generalizable
4. ⚠️ **Partial FL**: Only statistical weights aggregated, not full models

### What Works Well:

1. ✅ **Gradient clipping**: Prevents poisoning attacks
2. ✅ **Trimmed mean**: Robust to outlier clients
3. ✅ **DP noise**: Some privacy protection in aggregation
4. ✅ **Convergence tracking**: Monitors model stability

### Recommended Changes:

1. **Stop sending raw data** - only model parameters + aggregated stats
2. **Pre-train on public datasets** - ensure models detect real threats
3. **Implement secure aggregation** - encrypted model updates
4. **Enhance DP** - client-side and server-side noise
5. **Validation framework** - use holdout test sets from CICIDS2017 etc.
