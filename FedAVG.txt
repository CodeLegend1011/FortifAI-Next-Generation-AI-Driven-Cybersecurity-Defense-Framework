# Detailed FedAvg Implementation Explanation

## Mathematical Foundation

### Current Implementation Analysis

Let me break down exactly how the FedAvg (Federated Averaging) algorithm is implemented in your FortifAI system:

---

## 1. **Model Parameters Structure**

Each client maintains three threshold parameters:

```python
θ = {
    'network_threshold': θ_n,
    'process_threshold': θ_p, 
    'file_threshold': θ_f
}
```

Where:
- `θ_n` ∈ ℝ: Network anomaly detection threshold
- `θ_p` ∈ ℝ: Process anomaly detection threshold  
- `θ_f` ∈ ℝ: Filesystem anomaly detection threshold

**Initial values:** `θ_n = θ_p = θ_f = 2.0`

---

## 2. **Local Training (Client Side)**

### Anomaly Detection Formula

Each client uses **z-score** based anomaly detection:

```
z = |x - μ| / σ

Where:
- x: current observation (e.g., number of connections)
- μ: mean of baseline (rolling window of last 100 observations)
- σ: standard deviation of baseline
```

**Anomaly Classification:**
```
is_anomaly = {
    True,  if z > θ
    False, otherwise
}
```

### Example Calculation:

```python
# Client 1 observes network connections over time
baseline_connections = [45, 50, 48, 52, 47, ..., 51]  # 100 values

# Current observation
x = 95  # connections

# Calculate statistics
μ = mean(baseline_connections) = 49.2
σ = std(baseline_connections) = 2.8

# Calculate z-score
z = |95 - 49.2| / 2.8 = 16.36

# Check against threshold
θ_n = 2.0
is_anomaly = (16.36 > 2.0) = True  ✓ Anomaly detected!
```

### Local Model Update

The client doesn't explicitly "train" - it simply maintains:
1. **Baseline statistics** (μ, σ) for each category
2. **Current thresholds** (θ_n, θ_p, θ_f)

**Model parameters sent to server:**
```python
model_params = {
    'weights': {
        'network_threshold': 2.0,
        'process_threshold': 2.0,
        'file_threshold': 2.0
    },
    'baselines': {
        'network': {'connections': [...], 'bytes': [...]},
        'process': {'count': [...], 'cpu': [...]},
        'file': {'events': [...]}
    }
}
```

---

## 3. **Server-Side Aggregation (FedAvg)**

### Mathematical Formulation

Given K clients that have sent updates, the server aggregates:

**Standard FedAvg Formula:**
```
θ_global = Σ(k=1 to K) [n_k/n * θ_k]

Where:
- θ_k: model parameters from client k
- n_k: number of samples from client k
- n = Σn_k: total samples across all clients
```

**Current Implementation (Simplified):**
```python
# Equal weight averaging (uniform FedAvg)
θ_global = (1/K) * Σ(k=1 to K) θ_k

Or equivalently:
θ_global = mean(θ_1, θ_2, ..., θ_K)
```

### Actual Code Implementation

```python
def aggregate_models(self):
    """Aggregate client models using FedAvg"""
    # Filter recent updates (last 10 minutes)
    recent_models = {client_id: data for client_id, data in self.client_models.items()
                     if data['timestamp'] > (now - 10 minutes)}
    
    K = len(recent_models)  # Number of clients
    
    # For each parameter (network_threshold, process_threshold, file_threshold)
    for key in ['network_threshold', 'process_threshold', 'file_threshold']:
        values = []
        
        # Collect parameter from each client
        for client_data in recent_models.values():
            θ_k = client_data['parameters']['weights'][key]
            values.append(θ_k)
        
        # Compute average
        θ_global[key] = (1/K) * sum(values)
    
    # Update global model version
    version += 1
```

## 5. **Model Distribution and Convergence**

### Distribution Back to Clients

After aggregation, all clients receive the **same** global model:

```
Server → Client 1: θ_global
Server → Client 2: θ_global
Server → Client 3: θ_global
```

### Client Update Logic


### Convergence Over Time

**Round 1:**

**Round 3, 4, 5... → Convergence**


The thresholds converge to values that work well across all client environments!

## 6. **Why This Works**

### Mathematical Properties

**1. Consensus Property:**
```
If all clients have similar environments:
θ_1 ≈ θ_2 ≈ θ_3 ≈ θ_k
→ θ_global ≈ θ_k  (no change needed)
```

**2. Balancing Property:**
```
If environments differ:
Client A: θ_A = 1.5 (too sensitive, many false positives)
Client B: θ_B = 3.5 (too relaxed, misses threats)
→ θ_global = 2.5 (balanced middle ground)
```

**3. Outlier Dampening:**
```
1 outlier client: θ_outlier = 10.0
99 normal clients: θ_normal ≈ 2.0
→ θ_global = (10 + 99*2)/100 = 2.08 (outlier has minimal impact)
```

## 7. **Current Implementation Limitations & Improvements**

### Current Limitation: Equal Weight Averaging

**Problem:**
```python
# All clients weighted equally, regardless of data size
θ_global = mean([θ_1, θ_2, θ_3])
```

A client with 10 observations has the same influence as one with 10,000!

### Improvement: Weighted FedAvg

**Better implementation:**

```python
def aggregate_models_weighted(self):
    """Weighted FedAvg based on sample counts"""
    
    total_samples = 0
    weighted_sums = {
        'network_threshold': 0.0,
        'process_threshold': 0.0,
        'file_threshold': 0.0
    }
    
    for client_id, client_data in recent_models.items():
        # Get number of samples from each client
        n_k = len(client_data['parameters']['baselines']['network']['connections'])
        total_samples += n_k
        
        # Weighted contribution
        for key in weighted_sums.keys():
            θ_k = client_data['parameters']['weights'][key]
            weighted_sums[key] += n_k * θ_k
    
    # Compute weighted average
    for key in weighted_sums.keys():
        θ_global[key] = weighted_sums[key] / total_samples
    
    return θ_global
```

**Mathematical formula:**
```
θ_global = Σ(k=1 to K) [(n_k/n) * θ_k]

Where:
- n_k = number of samples from client k
- n = Σn_k = total samples
```

**Example:**
```
Client 1: 1000 samples, θ_1 = 2.0
Client 2: 100 samples,  θ_2 = 5.0
Client 3: 10 samples,   θ_3 = 8.0

Equal weight:
θ_global = (2.0 + 5.0 + 8.0) / 3 = 5.0

Weighted:
n = 1000 + 100 + 10 = 1110
θ_global = (1000/1110)*2.0 + (100/1110)*5.0 + (10/1110)*8.0
θ_global = 1.80 + 0.45 + 0.07 = 2.32

Much better! Client 1 (with most data) has strongest influence.
```

## 8. **Privacy Guarantees**

### What is Shared
```
Client → Server:
{
    'weights': {'network_threshold': 2.5, ...},  # ✓ Only thresholds
    'baselines': {
        'network': {'connections': [45, 50, 48, ...]},  # ✓ Statistics only
    }
}
```

### What is NOT Shared
```
❌ Raw network packets
❌ Actual IP addresses
❌ Process names
❌ File contents
❌ User credentials
❌ Any personally identifiable information (PII)
```

### Differential Privacy (Optional Enhancement)

Add noise to parameters before sending:

```python
def add_privacy_noise(θ, epsilon=0.1):
    """Add Laplace noise for differential privacy"""
    noise = np.random.laplace(0, 1/epsilon, size=θ.shape)
    return θ + noise

# Client sends
θ_noisy = add_privacy_noise(θ_client, epsilon=0.1)
```

This provides **ε-differential privacy** guarantee!
